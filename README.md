# Chatbot-SQL-Agent

Created a chatbot using SQL Agent,Langchain and Groq

**Queries asked:**

List all student records.

List all student info records.

List all students in Class Data Science with marks > 85.

Get phone numbers of students in Section A.Join tables if needed.

**Use Cases:**

Non-technical users: People who need data but don’t know SQL.

Data analysts: Quickly test queries without writing boilerplate SQL.

Teachers or Admins: For your studentdb, you could easily ask things like:

“List all students in Class Data Science with marks > 85”

“Get phone numbers of students in Section A”

Business applications: Any app where decision-makers want to query databases conversationally.
